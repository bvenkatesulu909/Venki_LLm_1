Overview

Venki_llm_1 is a real, working decoder-only transformer implemented by hand in PyTorch. Every core component — the byte-level BPE tokenizer, the causal multi-head self-attention, the training loop, and the 2-bit quantizer — is written from scratch with no shortcuts. It is pre-trained by next-token prediction on ~1.4 million tokens of public-domain literature, then alignment-tuned with supervised fine-tuning (SFT) on instruction data, and finally compressed to 2 bits for a tiny footprint.

The 5-stage pipeline

Stage 1Tokenizer — byte-level BPE from scratch

The corpus is pre-tokenized with the GPT-2 regex, then every byte is mapped to a printable Unicode glyph (reversible UTF-8). A frequency-map merge learner repeatedly merges the most common adjacent pair until the vocabulary reaches 4000 tokens.

bpe = Tokenizer(vocab_size=4000)
bpe.train(open("data/corpus.txt").read())   # ~200KB subsample
ids = bpe.encode("Venki_llm_1 is a small model")
assert bpe.decode(ids) == "Venki_llm_1 is a small model"  # round-trip
Stage 2Architecture — GPT-style Transformer

Token embedding + learned positional embedding, pre-LayerNorm residual blocks, explicit causal self-attention (lower-triangular mask), GELU MLP, and a weight-tied output head. Scaled initialization for the projection layers.

att = (q @ k.transpose(-2,-1)) * (1/sqrt(head_dim))
att = att.masked_fill(causal_mask == 0, -inf)
att = softmax(att)
y   = att @ v                       # (B, n_head, T, head_dim)
Stage 3Pre-training — next-token prediction

Corpus → encode → vectorized random-window dataset (pre-drawn spans, not stride-1). AdamW with linear warmup + cosine decay, gradient clipping, and incremental best.pt saving on loss improvement.

python train.py --vocab_size 4000 --n_layer 4 --n_head 4 --n_embd 192 \
    --block_size 128 --batch_size 64 --steps 3000

Loss falls from ≈ ln(4000) ≈ 8.3 (random) toward a few; perplexity drops with it.

Stage 4Alignment — Supervised Fine-Tuning

Each instruction pair is formatted with a prompt template; prompt tokens are masked (labels = -100) so the loss is computed only on the response.

python finetune.py --data data/sft.jsonl --base out/best.pt
Stage 5Compression — 2-bit group quantization

The big 2-D weight matrices are quantized from 32-bit float to 2 bits (4 levels {0,1,2,3}) with a per-group scale+min. LayerNorm / bias / positional embeddings stay float. The model shrinks ~10× with only a small reconstruction error.

python quantize.py --out_dir out        # -> venki_llm_2bit.pt
python generate.py --out_dir out --ckpt venki_llm_2bit.pt --prompt "Venki_llm_1 is"

Run it yourself

# 1. environment (Windows host, Python 3.12 venv — torch has no 3.14 wheel)
uv venv --python 3.12 .venv
./.venv/Scripts/python.exe -m ensurepip --upgrade
unset PYTHONPATH
./.venv/Scripts/python.exe -m pip install torch==2.9.0+cpu --index-url https://download.pytorch.org/whl/cpu numpy regex

# 2. prepare corpus
./.venv/Scripts/python.exe preprocess.py

# 3. train
./.venv/Scripts/python.exe train.py --vocab_size 4000 --n_layer 4 --n_head 4 \
    --n_embd 192 --block_size 128 --batch_size 64 --steps 3000

# 4. generate
./.venv/Scripts/python.exe generate.py --prompt "Venki_llm_1 is"

# 5. align + quantize
./.venv/Scripts/python.exe finetune.py --data data/sft.jsonl --base out/best.pt
./.venv/Scripts/python.exe quantize.py --out_dir out
